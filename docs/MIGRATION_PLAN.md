# Codebase Migration Plan

This migration is intentionally staged. The audit and research plan are the
first deliverables; implementation changes must not silently convert the
current exploratory results into evidence for the new protocol.

## KEEP

- `src/data_audit.py` as the starting point for streaming schema and edge
  checks, after adding checksums, missingness, duplicates, and provenance.
- Chunked CSV reading and integer address indexing in `src/community.py`.
- Explicit duplicate-edge aggregation and the current memory-conscious full
  graph renderer, with improved metadata.
- Label exclusion from feature construction and the explicit unknown-label
  policy, after renaming metrics to expose denominators.
- Leiden as a graph-community baseline, not as the claimed contribution.
- Existing exploratory figures and results as historical artifacts, moved to a
  versioned exploratory area and marked non-authoritative.

## REFACTOR

- Move flat modules into clear packages: `data`, `preprocessing`, `graph`,
  `features`, `embeddings`, `clustering`, `evaluation`, `experiments`,
  `visualization`, and `utils`.
- Make `config/experiment.json` the single configuration source. CLI overrides
  must be recorded in the run manifest.
- Split full-history descriptive features from cutoff-aware temporal features.
- Replace `cluster_size` with `total_count`, `known_count`, and `unknown_count`.
- Separate representation fitting, assignment, label evaluation, and
  selection so final labels cannot influence choices.
- Add partition similarity, actor-ranking metrics, uncertainty intervals, and
  selection-aware null tests.
- Add input hashes, package versions, git revision, peak memory, runtime, and
  configuration to every run.
- Pin dependencies and add a minimal package/test configuration.
- Make output paths run-specific and refuse to overwrite without an explicit
  flag.

## REWRITE

- `src/temporal.py`: current independent early/late fits and the checked-in ARI
  1.0 artifact do not implement a valid temporal evaluation. Rewrite around
  cutoff-specific feature/graph construction and train/validation/test splits.
- `src/multiview.py`: retain the mathematical residual as a baseline, but
  rewrite the surrounding method so actor scores, calibration, and evaluation
  are explicit and held out.
- `src/run_experiments.py`: replace hard-coded settings and one-sample output
  with a configuration-driven, repeated, run-isolated experiment runner.
- `src/evaluation.py`: implement ranking, community, uncertainty, and
  denominator-safe metrics; keep ARI/NMI as secondary metrics.
- Notebook workflows: reduce notebooks to visualization and analysis of saved
  tables; they must not be authoritative experiment runners.

## DELETE or quarantine

- The orphan `results/temporal_stability.csv` until regenerated by the new
  protocol.
- Cached `models/*.joblib` files unless their manifest records the exact input
  hash, preprocessing, seed, and code revision.
- Claims in README/report describing current outputs as “paper-ready”, temporal,
  or detector results.
- Any generated result that cannot be tied to a command, configuration, input
  hash, and code revision. Preserve it only under `results/exploratory/` with a
  provenance warning.
- Empty package placeholders once real modules are moved, or populate them
  consistently rather than maintaining two import surfaces.

## ADD

- `docs/DATA_PROVENANCE.md` with official source, version, license, checksums,
  schema, and verified timestep semantics.
- `configs/` with separate descriptive, temporal, ablation, and robustness
  configurations.
- `src/data/provenance.py`, `src/data/splits.py`, and `src/data/schema.py`.
- `src/graph/views.py` for directed/weighted/symmetrized graph policies and
  graph statistics.
- `src/features/temporal.py` for cutoff-aware recency, duration, variability,
  and missingness features.
- `src/embeddings/` for a minimal Node2Vec baseline and later temporal methods
  only when justified.
- `src/evaluation/ranking.py`, `communities.py`, `uncertainty.py`, and
  `selection.py`.
- `src/experiments/runner.py`, `manifest.py`, and `artifacts.py` with atomic
  run directories.
- `tests/` covering address alignment, duplicate/self-loop policies, cutoff
  exclusion, label exclusion, deterministic seeds, and permutation invariants.
- `results/raw`, `results/processed`, `results/metrics`, `results/embeddings`,
  `results/clusters`, and `results/runs` with a documented retention policy.

## Migration order and checks

1. Verify dataset provenance and write schema tests.
2. Freeze current exploratory outputs and add provenance warnings.
3. Implement deterministic configuration and run manifests.
4. Implement graph-view and cutoff-aware feature builders.
5. Add baseline and held-out evaluation tests on a tiny fixture.
6. Re-run Leiden, Louvain, degree, behaviour, and residual baselines.
7. Add ablations and robustness experiments.
8. Generate paper tables/figures only from run artifacts.
9. Update README and report after results are regenerated; never hand-edit
   numeric results into prose.

The first post-migration acceptance check is not a better score. It is that a
second run from the same manifest reproduces the same rows, and that changing a
cutoff cannot access future edges or actor-time records.
